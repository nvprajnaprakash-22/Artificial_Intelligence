# AI & Systems Engineering from Scratch

Hi! I am a B.Tech student exploring how AI systems work under the hood by building them completely from scratch—without relying on high-level AI libraries or frameworks.

This repository serves as a hands-on record of my learning journey across symbolic reasoning, computational logic, and systems engineering.
